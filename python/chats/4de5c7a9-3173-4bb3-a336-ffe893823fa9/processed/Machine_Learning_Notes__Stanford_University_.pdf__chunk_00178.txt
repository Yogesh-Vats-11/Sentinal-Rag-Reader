Binary classiﬁcation. Next we deﬁne the model and loss function for
binary classiﬁcation. Suppose the inputs x∈Rd. Let ¯hθ:Rd→Rbe a
parameterized model (the analog of θ⊤xin logistic linear regression). We
call the output ¯hθ(x)∈Rthe logit. Analogous to Section 2.1, we use the
logistic function g(·) to turn the logit ¯hθ(x) to a probability hθ(x)∈[0,1]:
hθ(x) =g(¯hθ(x)) = 1/(1 + exp(−¯hθ(x)). (7.3)
