Bellman’s equations can be used to eﬃciently solve for Vπ. Speciﬁcally,
in a ﬁnite-state MDP ( |S|<∞), we can write down one such equation for
Vπ(s) for every state s. This gives us a set of |S|linear equations in |S|
variables (the unknown Vπ(s)’s, one for each state), which can be eﬃciently
solved for the Vπ(s)’s.
